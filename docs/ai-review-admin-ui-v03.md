# 어드민 UI 가이드 v0.3 — AI 검토 및 반영 기록

- 기록일: 2026-10-03
- 대상: admin-ui-standard-guide.md v0.2 → v0.3
- 상태: 외부 검토 반영 초안. 정책 확정 및 Claude 검토 전.

## 1. 수행 근거

| AI | 현재 기록 | 확인 한계 |
|---|---|---|
| Gemini | 직전 Gemini 검토 요청 흐름에서 사용자가 전달한 검토문을 반영 | 제공 문구에는 서비스명·모델·실행 ID·공유 링크가 없어 실제 제공자를 독립 확인할 수 없음 |
| ChatGPT | 본 대화에서 v0.2 작성 및 제공 검토의 판단·v0.3 수정 수행 | 이 문서가 ChatGPT 작업 기록이며 공급자 API 실행 기록은 아님 |
| Claude | 아직 검토 결과 없음 | 세 AI 검토 완료로 표시하지 않음 |

## 2. 전달된 검토 요지 및 판단

원문을 재구성한 요약이며 외부 AI가 직접 작성한 원문 파일은 아니다.

| 검토 항목 | 관련 절 | 반영 판단 | v0.3 처리 |
|---|---|---|---|
| PT-10·PT-11과 기본 패턴의 역할 혼선 | 3, 3.1 | 반영 | BT-01 결재·승인, BT-02 일괄 지급 템플릿으로 분리. 이전 ID 대응 명시 |
| 전체 적용과 선택적 노출의 의미 불명확 | 2 | 부분 반영 | 사용자 확정 요구 유지. 공통 지원 및 노출 방식은 미확정. 검토 제안만으로 확정 격상하지 않음 |
| 원문 열람과 반출 권한 관계 불명확 | 11.2~11.4 | 반영 | 기본 제안은 원문 열람·반출 권한 모두 요구. 승인만으로 권한 우회 불가. 예외는 미정 |
| MDI 동시 수정·삭제·승인 충돌 누락 | 4.1, 11.5 | 반영 | 저장 시 버전·상태 검증, 충돌 안내, 최신 조회 |
| 세션 만료 시 작성 데이터 보존 | 4.1, 11.5 | 부분 반영 | 미확정으로 유지. 개인정보 Local Storage 자동 보관은 기본 적용하지 않음 |
| 엑셀 오류 행 식별과 마스킹 충돌 | 7.3, 11.5 | 반영 | 원본 행 번호·실행 ID·오류 코드 사용, 원문 제외. 부분 성공 재업로드의 중복 방지 추가 |
| 지급 타임아웃 결과 미확정 UI 누락 | 7.2, 11.5 | 반영 | ‘지급 확인 필요’ 표시, 재지급 차단, 결과 조회·대사. 타임아웃을 강제 실패로 바꾸지 않음 |
| 정책 수치 확정 권고 | 9, 11.7 | 보류 | 최대 탭 수·재마스킹 시간·부분 반영을 임의 지정하지 않음 |

PT-01~09에도 일괄 처리·단계 진행 같은 상호작용이 포함되므로 ‘순수 레이아웃’으로만 정의하지 않고 기본 화면 패턴으로 표현했다.

## 3. 남은 결정

- 공통 기능 전체 적용이 전체 버튼 노출인지, 전역 지원 및 화면별 적용인지.
- MDI 최대 탭 수, 중복 열기, 작성 데이터 임시 보존.
- 원문 열람·반출 권한, 사유·승인·재마스킹 기준.
- 업로드 전체/부분 반영, 재업로드 중복 처리.
- 지급 결과 확인 수단, 수동 확정 근거·권한·승인.

## 4. Claude 검토 요청문

다음 문구와 함께 admin-ui-standard-guide.md v0.3을 첨부한다.

> 어드민 표준 UI 가이드 v0.3을 검토해 주세요. 확정 요구사항은 변경하지 말고, 제안·미확정 사항을 확정으로 취급하지 마세요. 기본 화면 패턴과 업무 템플릿의 분리, 공통 기능 전체 적용 해석, 원문 열람·반출 권한의 관계, MDI 동시 수정 및 세션 만료, 엑셀 오류 리포트와 재업로드, 지급 결과 미확정 및 중복 지급 방지에 집중하세요. 각 의견에 절 번호, 문제 상황, 영향, 수정안을 적어 주세요. 법적 수치나 개인정보 항목은 근거 없이 확정하지 마세요.

Claude 결과가 제공되면 출처·검토 의견·반영 판단을 후속 기록으로 추가한다.
