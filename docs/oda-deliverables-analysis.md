# 산업 ODA 수행기관 산출물 보완 분석

**2026년 11월 9일 · KOTRA ODA 통합관리시스템 설계 검토안**

근거는 「2026년 산업 ODA 업무 개요」(2026.6.) 제4장입니다. 절 번호는 제4장 내 번호입니다. 원문에서 수행기관의 제출이나 작성이 확인되는 자료와, 업무 수행에 따라 시스템에 등록할 자료를 구분했습니다. 산업부·KIAT 절차의 KOTRA 적용 여부는 담당 부서와 확정합니다.

## 4. 시스템 반영안

| 기능 | 설계 기준 | 확인할 예외 |
|---|---|---|
| 제출 과제 생성 | 사업유형·연차·활동·재원·지원 여부에 따라 산출물 적용 | 다년도 과제, 일정 변경, 중도종료, 대상 제외 |
| 공통 산출물 관리 | 사업·연차·산출물 유형·작성/제출/검토기관·기한·필수 여부·언어·서식 버전 기록 | TASK 국·영문 중 한쪽 누락, 외부기관 공동제출 |
| 제출·검토 | 작성·제출·보완요청·재제출·확정 상태와 버전 보존 | 제출 취소, 마감 후 정정, 보완기한 변경 |
| 유형별 연결 | 프로젝트형은 세부활동·검수·인계 대상, TASK형은 대상기업·진단·지도 회차 연결 | 프로젝트 병행 활동, TASK 회차 변경 |
| 사업비 자료 | 출연금과 보조금 이월금의 교부·집행·정산 자료를 구분 | RCMS·e나라도움 자료의 조회·송수신·직접등록 분담 |
| 종료 후 제출 | 수행기간 자료를 확정한 뒤 사후보고 대상·기한·담당자를 별도 관리 | 담당자 교체, 미제출, 지원 재개, 후속사업화 |

## 5. 고객사 확인사항

1. 사업유형·연차별 필수 제출 목록, 서식 및 기한을 공고문·협약·별첨으로 확인합니다.
2. 프로젝트형 최종보고서 제출 여부, 인계 증빙의 확인권자와 최종평가 선후관계를 정합니다.
3. 성과활용현황보고서와 성과활용보고서의 서식 관계, TASK의 제출 기간, 사후지원 종료평가 조건을 확인합니다.
4. 출연금·보조금 이월금별 자료 원천, 정산 대상, 제출·확정 역할을 정합니다.
5. 산업부·KIAT 절차에서 KOTRA 사업에 적용할 단계와 실제 승인 주체를 확정합니다.
